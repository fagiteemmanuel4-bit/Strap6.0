08 · MCP & AI connections

External AI clients connect to Strap through the remote MCP server and OAuth approval.

Available
⌘

MCP settings page

Copy endpoint, view connected clients, manage access and inspect activity.

pages.jsmcp route
  • MCP endpoint copy control
  • Connected OAuth apps and favicon / identity
  • Read-only or read/write permissions
  • Branch access controls
  • Revoke / restore connection
  • Available tool list and recent activity
  • Private access token controls
↪

OAuth sign-in

Hosted Strap login/continuation page for external AI clients.

mcp-login.htmlOAuth
Provides the user-facing sign-in hand-off for the MCP authorization flow.
✓

OAuth consent

Review the requesting app, choose permissions and branches, then approve.

mcp-consent.htmlOAuth
Consent screen is a separate experience from the dashboard MCP settings page.
⚒

MCP tool server

Remote API exposes read and write operations to approved clients.

mcp-server.jsapi/[...route].js
The dashboard lists read tools for store, branches, products, stock, sales and customers, with write tools for products, stock and image uploads.
